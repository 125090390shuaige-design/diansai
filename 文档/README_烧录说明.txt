ESP32S3-Cam 手机热点 STA 高流畅图传固件
=========================================

热点配置
--------
名称（SSID）：nihao
密码：welcometohere

手机设置
--------
1. 打开手机热点，并启用 2.4 GHz 或“最大兼容性”。
2. 热点名称和密码必须与上面完全一致，区分大小写。
3. 电脑也连接同一个热点。

烧录方法
--------
1. 打开乐鑫 Flash Download Tool 3.9.7。
2. ChipType 选择 ESP32-S3，WorkMode 选择 Develop。
3. 只勾选 CameraWebServer_STA_0x0.bin，地址填写 0x0。
4. 勾选 DoNotChgBin；选择正确串口。
5. 建议先 ERASE，再 START；完成后按模块 RESET。

使用方法
--------
1. 串口波特率设为 115200。
2. 等待串口显示 WiFi connected 和 Camera Ready。
3. 记下串口显示的 IP 地址。
4. 浏览器打开 http://<IP>，或启动“电脑录像工具”并填写该 IP。

本版本优化
----------
- 模块传感器是 GC2145，不支持原生 JPEG。
- 改为 GC2145 原生 YUV422 输出，避免旧 RGB565 路径的额外颜色转换。
- 使用乐鑫 esp_new_jpeg 1.0.0，启用 ESP32-S3 SIMD、双核和 DRAM 分块编码。
- 默认分辨率为 QVGA 320x240，JPEG 质量 80；采用历史长录像中实测最稳定的帧率配置。
- 限制 GC2145 的最慢自动曝光档，防止环境变暗后曝光时间翻倍并拖低源帧率。
- 双摄像头缓冲并只取最新帧，Wi-Fi 休眠关闭。
- 关闭人脸检测和识别，避免拖慢连续图传。
- 网络仍是标准 MJPEG；现有浏览器、BAT 和录像工具不需要更改。

如果仍然卡顿
------------
- 确认电脑和模块都连接 nihao 热点，且热点使用 2.4 GHz。
- 只保留一个上游视频连接；电脑录像工具会用同一连接同时预览和录像。
- 如果实际帧率仍不足，确认没有同时打开开发板原始网页和电脑录像工具。
- 串口会输出 MJPG: ... fps，可用于判断模块实际帧率。
